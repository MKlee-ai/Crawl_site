# Crawl Site

무신사/네이버 등에서 상품 랭킹·순위·리뷰 텍스트 정보를 수집해, AI 모델 스타일링 콘텐츠와 연동할 사이트(도메인)를 구축하는 프로젝트입니다.

## 프로젝트 범위

- 크롤링 코드, 데이터 수집/정제, 사이트 개발만 다룹니다.
- AI 캐릭터/콘텐츠 기획 관련 논의는 다루지 않습니다 (별도 프로젝트인 project-ai-model에서 진행).

## 현재 단계

아직 시작 전입니다. Phase 4(확장 결정) 이후 본격 착수 예정이며, 초반에는 SNS/유튜브만으로 진행합니다.

## 핵심 원칙

- 브랜드 사이트(ZARA, 유니클로 등) 이미지 직접 크롤링 금지 — 저작권 침해 위험
- 수집 가능한 건 "사실 정보"(랭킹, 순위, 텍스트 리뷰)에 한정, 이미지는 공식 제휴 프로그램 경로로만
- 무신사 파트너스 등 제휴 프로그램 약관상 "이미지 재가공 허용 범위" 확인 전까지 이미지 재가공 로직 개발 보류
- 크롤링 시 각 사이트 robots.txt / 이용약관 준수

## 폴더 구조

```
crawlers/   크롤링 스크립트/모듈
data/       수집·정제된 데이터 (raw/processed)
site/       사이트(프론트/백엔드) 코드
docs/       기획서/설계 문서 (옵시디언용, 마크다운 + frontmatter)
```

## 산출물 형식

- 옵시디언에 기록할 기획서/설계문서는 마크다운 + frontmatter 형식을 따릅니다.
- 코드는 일반적인 코드 컨벤션을 따르며, 마크다운 형식을 강제하지 않습니다.
