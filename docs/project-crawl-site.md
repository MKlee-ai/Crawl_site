## 목적

무신사/네이버 등에서 상품 랭킹·순위·리뷰 텍스트 정보를 수집해,
AI 모델 스타일링 콘텐츠와 연동할 사이트(도메인)를 구축.

## 프로젝트 범위

- 크롤링 코드, 데이터 수집/정제, 사이트 개발만 다룸
- AI 캐릭터/콘텐츠 기획 관련 논의는 다루지 않음 — project-ai-model에서 진행

## 사용 툴 & 역할

| 툴 | 용도 |
|---|---|
| Claude Code | 크롤러/스크래퍼 스크립트 작성, 사이트 개발(백엔드/프론트) |
| MCP / CLI | 정기 크롤링 자동화, 배치 실행 |
| (미정) DB | 수집 데이터 저장소 — 착수 시점에 규모 보고 선정 (SQLite부터 시작 권장) |
| (미정) 배포 환경 | 사이트 배포용 — 착수 시점에 결정 |

## 작업 방법 (크롤링 & 개발 워크플로우)

1. 각 대상 사이트의 robots.txt / 이용약관 먼저 확인 (수집 가능 범위 확정)
2. 수집 대상은 "텍스트 정보"(랭킹, 순위, 리뷰 요약)로 한정, 이미지는 제휴 프로그램 경로만
3. 크롤러는 소량 테스트 → 안정화 후 스케줄링(정기 실행) 순으로 확장
4. 수집 데이터는 스키마 먼저 설계(상품명/브랜드/가격/랭킹/리뷰요약 등) 후 저장 로직 작성
5. 사이트 개발은 MVP(최소 기능) 우선 — 상품 리스트+링크 노출부터, 고급 기능은 이후 반복 추가
6. 코드는 함수/모듈 단위로 작게 유지, 커밋 전 사이트별 약관 위반 여부 재확인

## 현재 단계

아직 시작 전 — Phase 4(확장 결정) 이후 착수 예정. 초반엔 SNS/유튜브만으로 진행.

## 핵심 원칙 (항상 체크)

- 브랜드 사이트(ZARA, 유니클로 등) 이미지 직접 크롤링 금지 — 저작권 침해 위험
- 수집 가능한 건 "사실 정보"에 한정, 이미지는 공식 제휴 프로그램 경로로만
- 무신사 파트너스 등 제휴 프로그램 약관상 "이미지 재가공 허용 범위" 확인 전까지 이미지 재가공 로직 개발 보류
- 크롤링 시 각 사이트 robots.txt / 이용약관 준수

## 산출물 형식

- 옵시디언에 기록할 기획서/설계문서만 마크다운 + frontmatter 형식 적용
- 코드는 일반적인 코드 컨벤션대로, 마크다운 형식 강제 안 함
