# 세로형 방치 RPG — PRD v0.1

> 이 문서는 **스토리 후보 5종(A~E)** 중 하나를 고르기 위한 초안입니다.
> 스토리가 정해지면 세계관·챕터 구성·캐릭터 시트를 확정한 v0.2로 업데이트합니다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 방치형(Idle) RPG + 가벼운 성장/수집 |
| 화면 | **세로(Portrait) 고정, 9:16 기준** — 폰을 돌리지 않고 한 손으로 플레이 |
| 진행 방향 | **종(세로) 스크롤** — 캐릭터가 위로 올라가거나(탑/하늘) 아래로 내려감(심연/바다) |
| 플랫폼 | 모바일 우선(Android/iOS), 웹(PWA) 동시 지원 검토 |
| 타깃 | 출퇴근·쉬는 시간에 1~3분씩 접속하는 라이트~미드코어 유저 |
| 차별점 | 방치형인데 **"다음 층에 뭐가 있는지 궁금하게 만드는" 스토리 중심 진행** |

### 1.1 한 줄 정의
"켜두면 알아서 오르고(내려가고), 들어올 때마다 이야기 한 조각이 열리는 세로형 방치 RPG."

### 1.2 목표
- 세션당 평균 2~3분, 하루 4회 이상 접속을 유도하는 루프
- 스토리 해금이 **복귀 동기**가 되도록 설계 (보상 + 다음 이야기)
- MVP는 8주 내 플레이 가능한 빌드

### 1.3 비목표 (MVP 기준)
- 실시간 PvP, 길드전
- 3D 그래픽, 가로 모드
- 대규모 가챠 경제 (MVP에서는 단순 상점만)

## 2. 화면 & 조작 (세로 모드 핵심 설계)

```
┌───────────────────┐
│ 재화 / 층수 / 설정 │  ← 상단 HUD (고정)
├───────────────────┤
│                   │
│   ▲ 다음 층       │
│   [적]  [적]      │  ← 전투 영역 (화면의 ~55%)
│      [주인공]     │     배경이 세로로 계속 스크롤
│   [동료] [동료]   │
│                   │
├───────────────────┤
│ 스킬1 스킬2 스킬3 │  ← 엄지 닿는 영역 (수동 발동/자동 토글)
├───────────────────┤
│ 성장│장비│동료│스토리│상점 │ ← 하단 탭바
└───────────────────┘
```

- **엄지 존 원칙**: 모든 주요 버튼은 화면 하단 40% 안에 배치
- **스크롤 연출**: 층을 클리어하면 카메라가 위(또는 아래)로 부드럽게 이동 → "올라가는 감각" 자체가 보상
- **스토리 컷신도 세로**: 웹툰식 세로 컷 / 채팅형 대사창으로 연출 (가로 컷신 금지)
- 안전 영역(노치, 하단 제스처 바) 대응 필수

## 3. 코어 루프

```
자동 전투 → 골드/경험치/장비 획득 → 성장(레벨·장비·스킬)
    ↑                                         ↓
 오프라인 보상 ← 앱 종료 ← 막힘(보스) ← 층 돌파 → 스토리 해금
                                         ↓
                                 일정 구간 후 환생(프레스티지)
```

| 루프 | 주기 | 내용 |
|---|---|---|
| 마이크로 | 수 초 | 자동 공격, 스킬 쿨다운, 드롭 |
| 세션 | 2~3분 | 오프라인 보상 수령 → 강화 → 보스 도전 → 스토리 1컷 |
| 데일리 | 1일 | 일일 퀘스트, 특수 던전, 출석 |
| 메타 | 1~2주 | 환생(프레스티지)으로 영구 버프, 새 챕터/지역 |

## 4. 주요 시스템

### 4.1 전투
- 완전 자동 전투 (스킬 자동 발동 토글 가능)
- 10층마다 보스. 보스는 제한 시간 내 처치 실패 시 이전 층에서 파밍 → "막힘"이 성장 동기
- 속성 상성 3종 (스토리에 맞게 명칭 변경)

### 4.2 성장
| 시스템 | 설명 |
|---|---|
| 레벨/스탯 | 골드로 공격·체력·치명 등 강화 (지수형 비용 곡선) |
| 장비 | 무기/방어구/장신구 3슬롯, 등급 5단계, 합성 |
| 스킬 | 액티브 3 + 패시브, 스킬북으로 레벨업 |
| 동료 | 스토리 진행으로 합류하는 동료 2명 동행 (스토리 연동 핵심) |
| 환생 | 일정 층 이상에서 리셋 → 영구 재화 획득 → 영구 버프 트리 |

### 4.3 방치/오프라인
- 오프라인 보상: 최대 8시간 누적 (업그레이드로 12시간까지)
- 복귀 시 "그동안 일어난 일" 요약 팝업 + 스토리 떡밥 한 줄

### 4.4 스토리 전달 방식
- **층 마일스톤 해금**: 10층(보스)마다 메인 스토리 1화
- **기록 조각 수집**: 일반 층에서 낮은 확률로 "일지/편지" 드롭 → 수집형 서브 스토리
- **동료 대화**: 대기 화면에서 동료끼리 짧은 대사 (호감도/관계 진행)
- **환생과 스토리 연결**: 환생이 세계관 안에서 설명돼야 함 (각 후보안에 명시)

## 5. 스토리 후보 (택 1)

> 각 안은 **세로 스크롤 방향**, **환생의 이유**, **방치의 이유**가 세계관 안에서 자연스럽게 설명되도록 설계했습니다.

### 🅰 「끝없는 탑의 등반자」 — 정통 판타지 / 상승형 ⬆
- **로그라인**: 하늘에 닿는 탑 꼭대기에 "소원을 이루는 종"이 있다. 동생을 되살리려는 소녀가 탑을 오른다.
- **세계관**: 탑은 층마다 다른 시대·문명이 봉인된 "기억의 저장소". 오를수록 세계의 비밀이 드러남.
- **주인공**: 리나(17), 망치를 든 대장장이 견습생
- **동료**: 말 많은 해골 기사 / 탑에서 태어난 정령 아이
- **환생 설명**: 탑에서 쓰러지면 1층에서 다시 깨어나지만 **기억(영구 버프)은 남는다** — 그리고 이것이 탑의 저주라는 게 중반 반전
- **챕터 흐름**: 숲의 층 → 사막 왕국 층 → 기계 도시 층 → 구름 위 신전 → 꼭대기의 종(진실: 종은 탑에 갇힌 사람들의 소원으로 움직임)
- **강점**: 이해하기 쉬움, 넓은 타깃, "위로 오른다"는 세로 화면과 완벽 일치
- **약점**: 익숙한 설정 — 연출·캐릭터 매력으로 차별화 필요

### 🅱 「심연 탐사대」 — 다크 판타지 / 하강형 ⬇
- **로그라인**: 지면에 뚫린 거대한 구멍. 내려갈수록 보물이 있지만, 돌아온 사람은 없다.
- **세계관**: 구멍 아래엔 과거 멸망한 지하 문명. 깊을수록 몸이 변이하며 강해지지만 인간성을 잃어감.
- **주인공**: 몰락한 탐사대의 막내 대원, 실종된 대장(엄마)을 찾아 내려감
- **동료**: 반쯤 변이된 전 대원 / 말하는 랜턴
- **환생 설명**: "귀환 의식" — 지상으로 돌아오면 변이가 풀리고 유물(영구 버프)만 남음
- **챕터 흐름**: 광산 → 버섯 숲 → 수몰 도시 → 뼈의 회랑 → 심연의 핵
- **강점**: 몰입감 높은 분위기, 떡밥형 스토리로 복귀율에 유리
- **약점**: 어두운 톤이 라이트 유저에게 진입장벽일 수 있음

### 🅲 「구름 위 배달부」 — 힐링 / 상승형 ⬆
- **로그라인**: 하늘 섬마다 편지를 배달하는 견습 배달부. 편지 속 사연이 하나의 큰 이야기로 이어진다.
- **세계관**: 땅이 사라지고 사람들이 떠다니는 섬에 사는 세계. 위로 갈수록 오래된 섬, 오래된 사연.
- **주인공**: 고양이 수인 배달부 "모모"
- **동료**: 무뚝뚝한 비행선 선장 / 편지를 먹는 작은 용
- **전투 설정**: 편지를 노리는 "잊혀짐 구름" 몬스터 퇴치
- **환생 설명**: 한 시즌 배달이 끝나면 새 배달 가방(새 시즌)으로 출발 — 쌓인 "감사 편지"가 영구 버프
- **강점**: 귀여운 캐릭터, 여성·라이트 유저 친화, 굿즈/IP 확장성
- **약점**: 전투 긴장감이 약할 수 있음 → 보스 연출로 보완

### 🅳 「100층 회사 탈출기」 — 현대 코미디 / 상승형 ⬆
- **로그라인**: 이세계 최대 기업 "마왕 주식회사" 1층 인턴으로 전생한 주인공. 꼭대기 층 회장실까지 승진(=돌파)하라.
- **세계관**: 층 = 부서. 총무팀 슬라임, 영업팀 오크, 법무팀 리치… 보스는 각 부서장.
- **주인공**: 과로로 쓰러진 K-직장인 "김대리"
- **동료**: 의욕 없는 같은 기수 엘프 / 퇴사를 꿈꾸는 드래곤 경비원
- **환생 설명**: "이직" — 회사를 나왔다가 경력직(영구 버프)으로 재입사
- **강점**: 공감형 개그, SNS 바이럴, 한국 유저 정서에 강함, 방치 = "칼퇴 후 자동 업무" 밈
- **약점**: 개그 톤 유지가 장기적으로 어려움, 깊은 감동은 약함

### 🅴 「심해 등대지기」 — 미스터리 SF / 하강형 ⬇
- **로그라인**: 바닷속으로 가라앉는 등대. 등대지기는 매일 한 층씩 더 깊이 빛을 비추며 "바다 밑에서 오는 신호"를 추적한다.
- **세계관**: 해수면 상승 이후의 근미래. 깊을수록 고대 문명/외계 흔적.
- **주인공**: 혼자 남은 등대지기 + 그와 대화하는 고장 난 AI
- **동료**: 잠수 드론 / 기억을 잃은 인어
- **환생 설명**: 산소가 바닥나면 수면으로 귀환, 수집한 데이터(영구 버프)로 장비 업그레이드
- **강점**: 독특한 분위기, 미스터리 떡밥으로 강한 복귀 동기
- **약점**: 아트·사운드 퀄리티 의존도 높음, 개발 비용 ↑

### 5.1 비교표

| 안 | 톤 | 방향 | 타깃 폭 | 복귀 동기(떡밥) | 제작 난이도 | 추천 |

## 6. MVP 범위 (8주)

| 포함 | 제외(이후) |
|---|---|
| 1개 챕터(1~50층, 보스 5종) | 2챕터 이후 |
| 자동 전투, 스킬 3종 | 스킬 트리 확장 |
| 레벨/스탯 강화, 장비 3슬롯 | 장비 세트 효과 |
| 동료 1명 | 동료 수집 |
| 오프라인 보상 | 푸시 알림 고도화 |
| 메인 스토리 5화 + 기록 조각 10개 | 서브 퀘스트 |
| 로컬 저장 | 클라우드 저장, 계정 |
| 환생 1단계 | 환생 트리 확장 |

### 마일스톤
| 주차 | 산출물 |
|---|---|
| 1 | 스토리 확정, 세로 화면 프로토타입(스크롤 + 자동 전투) |
| 2~3 | 성장 시스템, 데이터 테이블(몬스터/층/보상) |
| 4 | 오프라인 보상, 저장/로드 |
| 5 | 스토리 뷰어(세로 컷/채팅형), 1~2화 연출 |
| 6 | 장비·동료·환생 |
| 7 | 밸런싱(목표: 50층까지 약 3일) |
| 8 | 테스트 빌드(PWA 또는 Android 내부 테스트) |

## 7. 기술 스택 (제안)

| 옵션 | 장점 | 단점 |
|---|---|---|
| **Phaser 3 + TypeScript + PWA** (추천) | 웹 즉시 배포, 빠른 반복, 세로 고정 쉬움, 나중에 Capacitor로 앱 포장 | 고사양 연출 한계 |
| Unity 2D | 앱 출시·광고 SDK 생태계 강함 | 빌드/반복 속도 느림, 학습 비용 |
| Godot 4 | 가볍고 무료, 2D 강함 | 모바일 광고/결제 플러그인 생태계 약함 |

- 데이터 주도 설계: 층/몬스터/스토리 대사를 JSON(또는 스프레드시트 → JSON)으로 관리 → 스토리 교체가 쉬움
- 큰 수 처리: `break_infinity.js` 등 방치형용 big number 라이브러리
- 오프라인 보상: 마지막 접속 타임스탬프 기반 계산 (서버 없이 MVP 가능, 시계 조작 방지는 이후)
