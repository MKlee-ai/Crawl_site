## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 픽셀 방치형 RPG (자동 전투 + 성장 + 무기·스탯 빌드) |
| 화면 | 세로(Portrait) 고정, 한 손 조작 |
| 진행 | 종(세로) 스크롤 — 탑을 위로 오름. 진행 단위는 **Stage** (Stage 1개 = 탑 1층) |
| 플랫폼 | Android (Google Play), 한국어 + 영어 동시 지원 |
| 핵심 재미 | ① 접속할 때마다 쌓여 있는 성장 ② **스탯 분배 = 내 무기 취향** ③ 보스의 방어 특성에 맞춰 무기 고르기 ④ 다음 Stage 이야기 |

**한 줄 정의**
역병에 걸린 동생을 살리기 위해, 떠돌이 검사 휴릭이 하늘에 닿은 종탑을 오른다. 탑의 시험은 하나 — 모든 무기를 다루는 자, **검제**가 되는 것.

## 2. 세계관 & 스토리

### 2.1 배경
- **알베른 왕국**: 가상의 중세 유럽풍 왕국. 성채, 수도원, 자유도시, 기사단이 있는 세계.
- **잿빛 역병**: 걸리면 피부가 잿빛 돌처럼 굳어가는 역병.
- **성 아르멜의 종탑**: 하룻밤 사이에 솟아오른 끝이 보이지 않는 탑. "꼭대기의 종을 울리는 자는 모든 역병을 거둔다"는 전설.
- **검제(Sword Emperor)**: 탑의 전설 속 칭호. 탑 안에 잠든 옛 무기의 주인들에게 인정받아 **모든 무기를 다룬 자**만이 종에 닿을 수 있다. → 무기 해금이 스토리 그 자체.

### 2.2 등장인물

| 인물 | 역할 | 설명 |
|---|---|---|
| **휴릭 (Hurick)** | 주인공 | 몰락한 기사 가문의 떠돌이 검사. 아버지의 평도 한 자루만 들고 탑에 오른다. |
| **엘라 (Ella)** | 동생 | 잿빛 역병 환자. 오빠에게 편지를 남긴다 (기록 조각 = 엘라의 편지). |
| **가레스 (Gareth)** | 동료 / 멘토 | 탑에서 만나는 능청스러운 해골 기사. 새 무기를 해금할 때마다 다루는 법을 알려주는 튜토리얼 담당. *정체가 핵심 반전.* |
| **마리엔 (Marien)** | 동료 / 회복 | 견습 수녀이자 연금술사. Stage 100에서 휴릭의 **마력**을 깨워준다(INT 해금). |
| **발드릭 (Baldric)** | 최종 보스 | 성기사단장, 종의 수호자. 그 자신도 검제가 되지 못한 자. |

### 2.3 회귀(환생) 설정
- 탑에서 쓰러지거나 "종의 맹세"를 하면 **종이 울리고 시간이 탑에 처음 들어온 날로 되돌아간다**.
- 레벨·장비는 사라지지만 **검의 기억(영구 재화 「각인」)**과 **무기 숙련도 일부**는 남는다 → 프레스티지.
- 회귀 횟수에 따라 NPC 대사가 달라짐 → 회귀 자체가 스토리 콘텐츠.

### 2.4 챕터 구성 (1장 = 50 Stage, 10 Stage마다 보스)

| 장 | Stage | 지역 | 무기 해금 | 새로 등장하는 적 특성 | 스토리 비트 |
|---|---|---|---|---|---|
| 프롤로그 | - | 고향 마을 | 평도 | - | 엘라의 발병, 아버지의 평도를 들고 출발 |
| 1장 | 1–50 | 무너진 성채 | 세검(20), 대검(40) | - | 가레스와 만남. 검제의 전설 |
| 2장 | 51–100 | 성 아르멜 지하묘지 | 둔기(70), **마검(100)** | 물리 방어력(50), 결계(80) | 마리엔 합류, 마력 각성 |
| 3장 | 101–150 | 용병 자유도시 | 마단검(130) | 마법 방어력(110), 재생(120) | 탑 안에 "시대가 다른 도시"가 있다 |
| 4장 | 151–200 | 철의 요새 | 마법대검(170), 마법둔기(200) | 슈퍼아머(150) | **첫 반전**: 탑의 기사들은 모두 회귀 중이었다 |
| 5장 | 201–250 | 마녀의 숲 | (무기 변형·전설 등급) | 특성 복합 | 역병의 기원은 탑. **두 번째 반전**: 가레스는 수백 번 회귀한 미래의 휴릭 |
| 6장 | 251–300 | 구름 위 대성당 | - | 특성 복합 | 종의 진실, 발드릭과의 결전, 검제 칭호 |
| 엔드 | 301+ | 무한 종루 | - | 랜덤 | 엔딩 이후 무한 Stage (랭킹·도전) |

- 무기 종류에는 상하 관계가 없으므로, 새 무기는 "더 센 무기"가 아니라 **"새 플레이 스타일"**로 소개
- 새 적 특성은 그 특성에 유리한 무기가 이미 해금된 뒤에 등장
- 엔딩 분기(종을 울린다 / 부순다)는 v1.0 이후 검토

### 2.5 스토리 전달 방식 (세로 화면용)
- **보스 클리어 → 메인 스토리 1화**: 세로 웹툰식 도트 컷 3~6장 + 대사창
- **무기 해금 컷신**: 옛 무기 주인의 혼과 대련 → 인정받으면 해금
- **기록 조각**: 일반 Stage에서 낮은 확률로 "엘라의 편지 / 기사들의 일지" 드롭
- **모닥불 대화**: 대기 화면에서 가레스·마리엔의 짧은 대화 (장착 무기·회귀 횟수에 따라 변화)
- **복귀 요약**: 오프라인 보상 팝업에 "그동안 가레스가 한 말" 한 줄

- 스토리 컷신도 세로 비율로만 제작

## 4. 코어 루프

```
자동 전투 → 골드/경험치/무기 드롭 → 레벨업(스탯 포인트) → 스탯 분배 & 무기 선택
   ↑                                                       ↓
오프라인 보상 ← 종료 ← 보스 방어 특성에 막힘 ← Stage 돌파 → 스토리 / 새 무기 해금
                                              ↓
                              회귀(프레스티지) → 각인으로 영구 강화
```

| 루프 | 주기 | 내용 |
|---|---|---|
| 마이크로 | 수 초 | 자동 공격, 스킬, 드롭 |
| 세션 | 2~3분 | 오프라인 보상 → 강화·스탯 조정 → 보스 도전 → 스토리 |
| 데일리 | 1일 | 일일 의뢰, 무기 숙련 던전, 출석 |
| 메타 | 1~2주 | 회귀, 새 챕터, 새 무기 빌드 |

## 6. 픽셀 아트

### 6.1 사양

| 항목 | 사양 |
|---|---|
| 논리 해상도 | 가로 180px 고정, 세로 320~400px (기기 비율에 따라 배경 확장) |
| 확대 방식 | 정수 배율 (1080px 폭 → ×6), 최근접 이웃 보간 |
| 캐릭터 | 32×32 (휴릭·일반 적), 보스 64×64 ~ 96×96 |
| 배경 | 16×16 타일 + 세로 패럴랙스 (챕터당 3레이어) |
| 팔레트 | 32색 제한 공용 팔레트 → 전체 톤 통일, AI 생성물도 이 팔레트로 보정 |
| 주인공 | **몸 + 무기 레이어 분리** → 무기를 바꾸면 겉모습도 바뀜 |
| 공격 모션 | 속도 등급 기준 3세트 공유: 찌르기(세검·마단검) / 베기(평도·마검) / 무거운 휘두르기(대검·둔기·마법대검·마법둔기). 마법 무기는 이펙트 레이어 추가 |
| 한글 폰트 | 픽셀 한글 폰트 (예: 갈무리 Galmuri, OFL) — 영문도 같은 폰트로 |
| 제작 툴 | Aseprite (스프라이트시트 + JSON 내보내기) |

### 6.2 제작 방식 — Claude Code + AI 도구 + 수작업 보정

| 단계 | 담당 | 내용 |
|---|---|---|
| 프로토타입 | **Claude Code** | 코드로 32×32 도트를 직접 생성 (샘플: `docs/assets/hurick-weapon-swap-sample.png`). 개발 초기에 바로 쓸 수 있는 임시 그래픽 |
| 본 그래픽 | **도트 전용 AI 도구** | PixelLab(애니메이션·방향 회전·Aseprite 플러그인), Retro Diffusion(Aseprite 확장, 일회성 구매) 등 |
| 보정 | 사람 (Aseprite) | 팔레트 통일, 프레임 간 흔들림 수정, 무기 레이어 분리 |
| 대안 | 에셋 구매 | itch.io 등 중세 판타지 도트 팩 — 상업 라이선스 확인 |

- Claude Code가 잘하는 것: 정적인 소형 스프라이트, 아이콘, UI 프레임, 타일 패턴, 팔레트 변환·스프라이트시트 정리 자동화
- Claude Code가 약한 것: 여러 프레임에 걸친 자연스러운 캐릭터 애니메이션, 큰 보스·일러스트급 컷신 → AI 도구 + 보정이 효율적
- **AI 도구는 사용 전 약관에서 상업적 이용·결과물 소유권을 반드시 확인** (요금제마다 다를 수 있음)

## 7. 기술 스택 (Android)

| 구성 | 선택 |
|---|---|
| 게임 | **Phaser + TypeScript** (`pixelArt: true`) — 모든 로직이 코드라 Claude Code로 개발하기 가장 좋음 |
| 빌드 | Vite → **Capacitor** → Android AAB → Google Play 내부 테스트 트랙 |
| 데이터 | `weapons.json`, `enemies.json`, `stages.json`, `story/*.json` — 데이터 주도 설계 |
| 다국어 | `locales/ko.json`, `locales/en.json` — 모든 텍스트는 키로 관리 (처음부터) |
| 큰 수 | 방치형용 big number 라이브러리 (예: break_infinity.js) |
| 저장 | 로컬 저장 → 이후 Google Play Games 클라우드 저장 |
| 광고 | AdMob 보상형 광고 (Capacitor 플러그인) |

대안: Godot 4(2D 강함, 에디터 중심), Unity 2D(SDK 생태계 최강, 무거움) — 자세한 비교는 v0.2 기록 참고.

## 9. 이름 검토 (해외 출시 고려)

### 9.1 주인공 이름 「Hurick」
- 영어권에 같은 철자의 단어·속어는 확인되지 않음 → **부정적 의미 없음, 사용 가능**
- 비슷한 이름: 아르메니아 이름 **Hurik**("작은 불"이라는 뜻의 여성 이름) — 철자가 달라 문제 되지 않음
- Eric, Ulric, Baldric처럼 **-ric/-rick으로 끝나는 게르만·중세풍 이름**과 어감이 비슷해 중세 유럽 배경에 잘 어울림
- 주의: 영어권에서는 **"허릭"**으로 읽힐 가능성이 큼 (한국어 "휴릭"에 가까운 발음을 원하면 Hyurick도 가능하나 낯선 철자). 음성 더빙이 없다면 Hurick 유지 추천

### 9.2 게임 제목
- 이미 비슷한 이름의 모바일 게임이 있음:
  - **Sword Master Story** (SuperPlanet, 방치형 액션 RPG, Google Play 출시)
  - **Idle Sword Master** (MAD PIXEL, **픽셀 방치형 RPG**)
- → "Sword Master Idle", "Idle Sword Master" 계열은 **검색에서 묻히고 혼동될 위험**이 커서 피하는 게 좋음
- 검제 = 검의 황제 → 영문은 **Sword Emperor**가 원뜻에 가깝고 위 게임들과도 겹치지 않음
- 제목 앞에 **고유명사(Hurick)**를 두면 검색·상표 측면에서 유리

| 후보 (EN) | KR | 비고 |
|---|---|---|
| **Sword Emperor Hurick** (추천) | 검제 키우기: 휴릭 | 원뜻 그대로, 고유명사 포함 |
| Hurick: Idle Sword Emperor | 검제 키우기 | 스토어 검색 키워드 "Idle" 포함 |
| Hurick and the Bell Tower | 휴릭과 종탑 | 스토리 강조, 장르가 덜 드러남 |

- 확정 전 **Google Play 검색 + 상표 검색**(한국 KIPRIS, 미국 USPTO) 필요
