# Sword Emperor Hurick (검제 키우기: 휴릭) — FRD v0.1

> 기획 배경·스토리: [[idle-rpg-prd]] / 전투 공식·수치: [[idle-rpg-combat]]
> 이 문서는 **"무엇을 만들어야 하는가"**를 기능 단위로 정리한 개발 기준 문서입니다.
> 우선순위: **P0** = MVP 필수 / **P1** = MVP 이후 v1.0 / **P2** = 이후 검토

## 1. 화면·렌더링 (SCR)

| ID | 요구사항 | 우선 | 완료 기준 |
|---|---|---|---|
| SCR-01 | 세로(Portrait) 고정. 가로 회전 시에도 세로 화면 유지 | P0 | Android 기기 회전 시 화면이 돌아가지 않음 |
| SCR-02 | 논리 해상도 가로 180px 고정, 세로 320~400px 가변 | P0 | 9:16 ~ 20:9 기기에서 좌우 여백 없이 표시 |
| SCR-03 | 정수 배율 확대 + 최근접 이웃 보간 | P0 | 도트 경계가 흐려지지 않음 |

| SCR-06 | 레이아웃: 상단 HUD / 전투 영역(~55%) / 스킬 바 / 하단 탭 5개(성장·무기·스탯·스토리·상점) | P0 | PRD §3 와이어프레임과 일치 |

## 3. 전투 (CBT)

| ID | 요구사항 | 우선 | 완료 기준 |
|---|---|---|---|
| CBT-01 | 완전 자동 전투 (일반 공격 자동) | P0 | 입력 없이 Stage 진행 |
| CBT-02 | 공격 주기 = 무기 속도 등급 (빠름 2.0 / 보통 1.25 / 느림 0.8 회/초) | P0 | 무기 교체 시 공격 간격 변경 |
| CBT-03 | 1타 공격력 = 속도 등급의 반비례 (50 / 80 / 125), 모든 종류 기본 DPS 동일 | P0 | 같은 등급·강화에서 DPS 차이 ±1% 이내 |
| CBT-04 | 피해 공식: 스탯 보정 `1 + 2 × Σ(비율 × s/(s+50))` | P0 | combat 문서 §4.1 표 수치를 단위 테스트로 재현 |
| CBT-05 | 물리 경감 `DEF / (DEF + 5 × 물리 1타)`, 마법 경감 = 마법방어력% − 마법관통% | P0(물리) / P1(마법) | §4.2 표 수치 재현 |
| CBT-06 | 치명타 (확률·피해) | P0 | |
| CBT-07 | 액티브 스킬 3슬롯, 자동 발동 토글(AUTO) + 수동 발동 | P0 | AUTO 끄면 수동 발동만 |
| CBT-08 | 피해 숫자 표시 (물리/마법/치명타 색 구분) | P0 | |
| CBT-09 | 상태이상: 출혈·기절·경직·방어 분쇄 | P0(경직·기절) / P1(출혈·분쇄) | |
